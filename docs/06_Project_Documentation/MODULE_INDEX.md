# 1. Purpose

Данный документ описывает логическую структуру модулей AI Archive Server и их взаимодействие.

Используется для:

- понимания архитектуры Runtime;
- навигации между модулями;
- описания ответственности компонентов;
- анализа взаимодействия подсистем.

# 3. Module Responsibilities

## Queue Manager

Назначение:

- принимает запросы на загрузку;
- создаёт записи в очереди;
- переводит модели в состояние `QUEUED`.

---

## Download Worker

Назначение:

- обрабатывает очередь загрузки;
- управляет конвейером загрузки;
- координирует работу остальных модулей;
- обновляет Registry.

---

## Model Cache

Назначение:

- проверяет наличие модели в локальном архиве;
- предотвращает повторную загрузку моделей;
- валидирует существующий архив.

Кэш считается корректным только при наличии:

- `manifest.json`;
- полной структуры архива;
- корректных контрольных сумм файлов.

При **cache hit** используется локальный архив без обращения к Hugging Face.

---

## HF Client

Назначение:

- взаимодействие с Hugging Face Hub;
- получение информации о моделях;
- получение метаданных;
- загрузка репозиториев;
- аутентификация.

---

## Archive Builder

Назначение:

- формирует структуру архива;
- создаёт `manifest.json`;
- организует хранение моделей.

---

## Storage

Назначение:

- хранение архивов моделей;
- управление структурой каталогов;
- работа с файлами архива.

---

## Model Registry

Назначение:

- хранение информации о моделях;
- управление состояниями моделей;
- история операций;
- интерфейс доступа к Registry.

---

## Query API

Назначение:

- доступ к Registry;
- поиск моделей;
- фильтрация;
- получение списков моделей.

---

## CLI

Назначение:

- административные операции;
- обслуживание системы;
- ручной запуск сервисных задач.

# 5. Architecture Principles

Каждый модуль должен:

- выполнять одну основную функцию;
- иметь минимальные зависимости;
- взаимодействовать через определённые интерфейсы;
- быть расширяемым без изменения существующей архитектуры;
- соответствовать принципу *Extend, never replace*.
