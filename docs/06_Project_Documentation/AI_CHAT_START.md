# AI_CHAT_START.md

# AI Archive Server

## AI Chat Initialization

Перед началом любой работы ОБЯЗАТЕЛЬНО ознакомься с документацией проекта.

Читать документы необходимо строго в следующем порядке.

---

## 1. CURRENT_STATUS.md

Определи:

- текущее состояние проекта;
- последний завершённый этап;
- текущую задачу разработки;
- следующий HF-этап.

CURRENT_STATUS.md является **единственным источником актуальной информации** о состоянии проекта.

---

## 2. PROJECT_CONTEXT.md

Изучи назначение проекта, его цели и область применения.

---

## 3. PROJECT_MAP.md

Изучи структуру проекта и расположение основных компонентов.

---

## 4. ROADMAP.md

Изучи общий план разработки и последовательность этапов.

---

## 5. CODING_STANDARDS.md

Все изменения кода должны соответствовать установленным правилам.

---

## 6. DECISIONS.md

Изучи все ранее принятые архитектурные решения.

Не предлагай решения, которые уже были отклонены.

---

## 7. FILE_INDEX.md

Используй для поиска файлов проекта.

---

## 8. MODULE_INDEX.md

Изучи взаимодействие модулей и архитектуру системы.

---

## 9. API_INDEX.md

Изучи публичные функции и интерфейсы проекта.

---

# После изучения документации

Перед началом работы:

1. Кратко опиши текущее состояние проекта.
2. Назови текущий HF-этап.
3. Назови следующую задачу разработки.
4. Только после этого приступай к написанию кода.

---

# Правила работы

- Не создавать новую архитектуру без необходимости.
- Не изменять принятые архитектурные решения.
- Следовать ROADMAP.md.
- Соблюдать CODING_STANDARDS.md.
- При возникновении противоречий приоритет имеют документы в следующем порядке:

1. CURRENT_STATUS.md
2. DECISIONS.md
3. ROADMAP.md
4. PROJECT_CONTEXT.md

---

# Обновление документации

После завершения каждого HF необходимо обновить документацию проекта.

Минимальный набор файлов:

- CURRENT_STATUS.md
- ROADMAP.md (если требуется)
- MODULE_INDEX.md (если изменилась архитектура)
- API_INDEX.md (если появились новые публичные функции)
- DECISIONS.md (если принято новое архитектурное решение)

---

AI_CHAT_START.md является загрузчиком документации и не содержит информации о текущем состоянии проекта.

Вся актуальная информация хранится исключительно в CURRENT_STATUS.md.
