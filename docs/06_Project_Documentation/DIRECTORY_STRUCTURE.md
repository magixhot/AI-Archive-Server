# DIRECTORY_STRUCTURE

Project: AI Infrastructure

Document ID: DOC-0001.3

Version: 1.0

Status: Active


# 1. Purpose

Данный документ описывает логическую структуру каталогов AI Infrastructure.

Его задача — определить назначение каждого каталога верхнего уровня.

Документ не является автоматически сгенерированным деревом файлов и не содержит описание отдельных файлов проекта.

Подробная структура файлов Runtime-проектов описывается в FILE_INDEX.md.


# 2. Root Structure

AI_Infrastructure

│
├── 00_Standards
├── 01_Infrastructure
├── 02_Models
├── 03_Containers
├── 04_Scripts
├── 05_Backups
└── 06_Project_Documentation


Каждый каталог верхнего уровня имеет строго определённое назначение.


# 3. Directory Description


## 00_Standards

Назначение:

Стандарты и нормативные документы проекта.

Содержит:

- стандарты хранения моделей;
- стандарты разработки;
- эксплуатационные стандарты;
- архитектурные соглашения.


## 01_Infrastructure

Назначение:

Описание аппаратной и программной инфраструктуры.

Содержит:

- серверы;
- рабочие станции;
- сетевую инфраструктуру;
- схемы размещения оборудования.


## 02_Models

Назначение:

Описание AI-моделей и политики их хранения.

Содержит:

- семейства моделей;
- классификацию моделей;
- политику хранения;
- сведения об архивных и рабочих версиях.


## 03_Containers

Назначение:

Контейнерная инфраструктура проекта.

Содержит:

- Docker Compose;
- Dockerfiles;
- шаблоны развёртывания;
- описание контейнерных сервисов.


## 04_Scripts

Назначение:

Служебные сценарии автоматизации.

Содержит:

- PowerShell;
- Python;
- Bash;
- вспомогательные утилиты.


## 05_Backups

Назначение:

Политика резервного копирования и восстановления.

Содержит:

- инструкции восстановления;
- схемы резервного копирования;
- описание архивов;
- процедуры восстановления.


## 06_Project_Documentation

Назначение:

Официальная документация AI Infrastructure.

Содержит Documentation Framework, описывающий архитектуру проекта, текущее состояние, инженерные правила, процесс разработки и историю изменений.

Основные документы:

- AI_CHAT_START.md
- PROJECT_CONTEXT.md
- PROJECT_MAP.md
- ROADMAP.md
- CURRENT_STATUS.md
- DIRECTORY_STRUCTURE.md
- FILE_INDEX.md
- COMPONENT_REGISTRY.md
- MODULE_INDEX.md
- API_INDEX.md
- CODING_STANDARDS.md
- DECISIONS.md
- ENGINEERING_WORKFLOW.md
- CHANGELOG.md


# 4. Documentation Rules

Каждый каталог верхнего уровня:

- имеет единственное назначение;
- не должен дублировать функции других каталогов;
- документируется при создании;
- поддерживается в актуальном состоянии.


При изменении структуры проекта необходимо обновить:

- DIRECTORY_STRUCTURE.md;
- PROJECT_CONTEXT.md (если изменилась архитектура проекта);
- CHANGELOG.md (если изменение является архитектурным).


# 5. Future Expansion

AI Infrastructure допускает расширение структуры новыми каталогами.

Каждый новый каталог обязан:

- иметь уникальное назначение;
- не дублировать существующие разделы;
- быть зарегистрирован в DIRECTORY_STRUCTURE.md;
- соответствовать архитектуре AI Infrastructure.

Если добавление нового каталога изменяет архитектуру проекта, соответствующие изменения должны быть отражены в PROJECT_CONTEXT.md.


# 6. Architecture Rule

Структура каталогов является частью архитектуры AI Infrastructure.

Любое изменение структуры каталогов считается архитектурным изменением и должно сопровождаться обновлением соответствующей документации.
